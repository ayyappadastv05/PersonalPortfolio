# Ayyappadas TV — Developer Portfolio

A high-end, responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Features
- Photo-led hero section
- Dark navy/blue palette matched to the supplied portrait
- Mouse-following ambient glow
- Pointer-reactive 3D tilt cards
- Magnetic buttons
- Particle field in the hero
- Scroll reveal animations
- Animated skill bars
- Active-section navigation
- Mobile navigation
- Reduced-motion accessibility support

## Run locally
Open `index.html` in a browser. No build step is required.

## Customize
- Replace `assets/profile.jpg` with another portrait using the same filename.
- Edit links and text inside `index.html`.
- Adjust colors in the `:root` section of `style.css`.
